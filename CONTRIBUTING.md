# Contributing to J.A.R.V.I.S

First off, thank you for considering contributing to J.A.R.V.I.S.!

## How Can I Contribute?

* **Reporting Bugs:** Use the GitHub Issues tab. Provide as much context as possible (OS, Python version, error logs).
* **Suggesting Enhancements:** Have an idea for a new skill or tool? Open an issue and let's discuss it!
* **Pull Requests:**
  1. Fork the repo and create your branch from `main`.
  2. If you've added code that should be tested, add tests.
  3. Ensure the test suite passes.
  4. Issue that pull request!

## Setting up for development

1. Follow the `README.md` instructions to install prerequisites.
2. We recommend creating a virtual environment: `python -m venv venv`.
3. Install dependencies: `pip install -r requirements.txt`.

## Coding Style

* Follow standard PEP 8 guidelines for Python.
* Keep functions small and modular.
* If you modify any frontend code, please ensure compatibility with Edge WebView2.

Thanks!
